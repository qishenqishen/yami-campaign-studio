# Yami 茶歇营销 Agent

[打开营销工作台](https://qishenqishen.github.io/yami-campaign-studio/)

以 Yami 北美食品电商「茶歇大会」为背景，围绕同一份客户简报完成目标判断、商品筛选、渠道创意和效果复盘。项目整理及实现由沈淇完成。

在「客户需求」选择新客首购并确认简报，进入选品后可以比较两套方案。锁定希望保留的商品，再把另一款设为缺货，便可查看替补和推荐依据。核对商品后，打开创意页获取渠道画面、文案和交付稿。

四个茶歇场景各有 12 款历史商品。界面给出场景、规格与历史陈列位，方便核对选品依据。价格、促销和区域可售性由活动运营在上线前核实。

## 本地运行

在项目根目录执行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000`。源码和场景图片都在 `assets/`。
